# Security policy

Report suspected vulnerabilities privately to [security@bibleit.app](mailto:security@bibleit.app).
Include the affected repository, version or commit, operating system, expected
and observed behavior, and a minimal reproduction or redacted proof of impact.

Do not include active tokens, browser cookies/codes, Live secrets, SSH private
keys, account exports or private server data. Use synthetic examples and explain
how sensitive evidence can be exchanged privately if needed. Avoid public issues
and pull requests containing vulnerability details before coordinated disclosure.

Reports for maintained source and released versions are welcome. Identify the
exact affected version; candidate validation is not a release support promise.
No response time or older-version backport schedule is promised here.
